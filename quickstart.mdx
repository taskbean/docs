## Prerequisites

- Node.js 22.13.0 or later for the npm CLI package
- A terminal in a Git repository for automatic Project and Workspace attribution
- Windows 10 or 11, Python 3.10+, and Foundry Local for the current desktop app dependency path

<Steps>
  <Step title="Install the CLI">

```bash
npm install -g taskbean
```

Confirm the install:

```bash
bean --version
```
  </Step>

  <Step title="Record a task">

```bash
bean add "Document the authentication flow"
bean list
bean start 1
bean done 1
bean report --date today
```

Taskbean resolves the current Workspace and rolls the task up to its Project.
  </Step>

  <Step title="Install the Agent Skill">

For GitHub Copilot:

```bash
bean install --agent copilot
```

For automatic detection of supported agent CLIs:

```bash
bean install --agent auto
```

See [Agent Skill](/cli/agent-skill) for Claude Code, Codex, OpenCode, global installs, and sandbox configuration.
  </Step>

  <Step title="Launch the desktop app">

From a clone of `taskbean/taskbean`, use the Windows launcher:

```powershell
cd app
.\launch.ps1
```

Or start the Python backend directly:

```bash
cd app/agent
pip install -r requirements.txt
python main.py
```

Open `http://127.0.0.1:8275`. The app reads the same `~/.taskbean/taskbean.db` file as the CLI.
  </Step>
</Steps>

<Info>
  The first local model download can take several minutes. Check `GET /api/health` for process state and `GET /api/ready` for model readiness.
</Info>
