The desktop backend serves a local FastAPI application. The default base URL is `http://127.0.0.1:8275`.

## Process and version

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/health` | Process health and model state; always returns `200` |
| `GET` | `/api/ready` | Readiness gate: `200`, `503`, or `500` |
| `GET` | `/api/version` | App, CLI, Git SHA, and start time |
| `GET` | `/api/port-info` | Current port configuration |
| `POST` | `/api/port` | Change the configured backend port |
| `GET` | `/api/launch-errors` | Recent launcher errors |

| `GET` | `/api/projects/tasks?project=<name>` |
| `POST` | `/api/projects/track` |

| `POST` | `/api/projects/{name}/delete` |
| `POST` | `/api/projects/{name}/untrack` |
| `GET` | `/api/task-detail/:task_id` |
| `GET` | `/api/task-detail/:task_id/export?format=md|json` |

## Models and configuration

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/models` | Foundry Local model catalog |
| `POST` | `/api/models/switch` | SSE model-switch progress |
| `GET`, `POST` | `/api/config` | Read or patch validated app config |
| `GET` | `/api/hardware` | CPU, memory, and accelerator snapshot |
| `GET` | `/api/hardware/eps` | Foundry Local execution providers |
