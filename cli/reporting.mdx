## Generate a report

```bash
bean report --date today
bean report --date week
bean report --date all --format json
bean report --date week --format csv
```

`--format` supports `md`, `json`, and `csv`. There is no separate `bean export` command.

## Interpret effort and token efficiency

Markdown and JSON reports include per-agent usage plus effort and token-efficiency data for enabled agents.

- Estimated effort uses three minutes per agent turn. Treat it as a read-only comparison metric, not elapsed time.
- Tokens per task divides tokens from sessions with linked Tasks by the number of linked Tasks.
- An agent without linked Tasks shows `N/A` in Markdown and has no `tokensPerTask` field in JSON.
- CSV reports contain Task rows only.

## Include Chronicle evidence

```bash
bean report --date week --include-chronicle
```

This adds linked evidence and suggestions that still need review. Without `--include-chronicle`, the report stays focused on canonical Taskbean tasks.

## Package work

```bash
bean package 42
bean package --date week --format json
```

Use packages when you need a focused task handoff or machine-readable evidence bundle. Use reports for time-based rollups.
