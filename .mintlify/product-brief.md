# Taskbean product brief

## Description

Taskbean is a local-first task manager for developers whose daily work includes coding agents. Its CLI lets agents record work as they perform it. Its desktop app lets developers review tasks, plan work, reconcile agent evidence, manage reminders, and produce reports without sending work data to a cloud service.

## Primary audience

Developers who work locally across repositories with GitHub Copilot, Claude, or other coding agents and need a trustworthy record of completed, pending, blocked, and follow-up work.

## Jobs to be done

- Install Taskbean and connect it to local agent workflows.
- Record, update, block, complete, and report tasks from the CLI.
- Understand how Projects, Workspaces, Agent Sessions, and Tasks relate.
- Review agent-created work and supporting evidence in the desktop app.
- Reconcile missed work and produce report-ready summaries.
- Keep task and usage data on the local machine.

## Motivation

Agent-assisted development produces useful work across many sessions and worktrees, but transcripts are poor task records. Taskbean makes the work visible and accountable with concrete status, source attribution, dates, evidence, and report-ready language.
